🚀 Deployment Guide

Shiprocket Invoice Entry Form — Google Sheets + Drive Integration

1
Create a Google Sheet
  1. Go to sheets.google.com and create a new blank spreadsheet.
  2. Name it "Shiprocket Invoice Tracker" (or any name you prefer).
  3. Keep this tab open — you'll need the URL later.
💡 Use a Google account that has access to the Google Drive folder where invoice PDFs should be stored.
2
Open Apps Script & Paste the Backend Code
  1. In your Google Sheet, click Extensions → Apps Script.
  2. Delete all existing code in the editor (Ctrl+A, Delete).
  3. Open the file Code.gs provided with this guide.
  4. Copy the entire contents and paste it into the Apps Script editor.
  5. Click 💾 Save (Ctrl+S).
💡 The script file is named Code.gs — make sure you copy the full file, from the first comment line to the last closing brace.
3
Run Setup Function Once
  1. In the Apps Script editor, select the function setupSheetAndFolder from the dropdown (top center).
  2. Click the ▶ Run button.
  3. When prompted, click "Review Permissions" → choose your Google account → click "Allow".
  4. Wait for it to complete — check the Execution log at the bottom for a success message.
✅ This creates: the "Invoice Submissions" sheet tab with all column headers, and a "Shiprocket Invoice Attachments" folder in your Google Drive.
⚠️ Only run this once. Running it again on an already-set-up sheet is safe but won't duplicate headers.
4
Deploy as Web App
  1. In the Apps Script editor, click Deploy → New deployment.
  2. Click the gear icon ⚙️ next to "Select type" and choose Web app.
  3. Set the fields as follows:
SettingValue
DescriptionShiprocket Invoice Form v2
Execute asMe (your Google account)
Who has accessAnyone
  1. Click Deploy.
  2. Copy the Web app URL — it looks like:
    https://script.google.com/macros/s/AKfycb.../exec
⚠️ Keep this URL private — anyone with it can submit to your sheet. Do not share it publicly.
5
Paste Web App URL into the Form
  1. Open Shiprocket_Invoice_Entry_Form_v31.html in a text editor.
  2. Search for the line (around line 2216):
var SCRIPT_URL = 'YOUR_GOOGLE_APPS_SCRIPT_URL_HERE';
  1. Replace YOUR_GOOGLE_APPS_SCRIPT_URL_HERE with your copied Web App URL:
var SCRIPT_URL = 'https://script.google.com/macros/s/AKfycb.../exec';
  1. Save the file.
💡 This is the only change needed in the HTML file. Everything else is already configured.
6
Host the Form on the Web
Choose one option

The form is a single self-contained HTML file. You can host it using any of these free options:

Option A — GitHub Pages (Recommended, Free)

  1. Go to github.com and create a free account (or log in).
  2. Create a new repository, e.g. shiprocket-invoice-form. Set it to Public.
  3. Upload the file — rename it to index.html before uploading.
  4. Go to Settings → Pages → under Source, select main branch → click Save.
  5. Your form will be live at: https://yourusername.github.io/shiprocket-invoice-form/
✅ GitHub Pages is free, reliable, and requires no server maintenance.

Option B — Netlify Drop (Instant, Free)

  1. Go to netlify.com/drop.
  2. Drag and drop the index.html file onto the page.
  3. Your form is instantly live at a random URL like https://xyz-abc-123.netlify.app.
  4. You can set a custom name in the Netlify dashboard.

Option C — Google Drive (No hosting needed)

  1. Upload the HTML file to Google Drive.
  2. Right-click → Get link → change to Anyone with the link.
  3. Share the link directly with your team.
⚠️ Google Drive preview mode may not run JavaScript. For Drive, users should download the file and open it in Chrome/Edge.
7
Test End-to-End
  1. Open your hosted form URL in Chrome or Edge.
  2. Attach a sample invoice PDF — the AI should auto-read and fill fields.
  3. Complete any missing fields manually.
  4. Click Review & Submit → verify the review screen → click Submit Invoice Entry.
  5. Open your Google Sheet — a new row should appear within seconds.
  6. Open Google Drive → Shiprocket Invoice Attachments folder → confirm the PDF was uploaded.
✅ If the row appears in the sheet AND the file appears in Drive, your deployment is complete!
💡 If submission fails, check: (1) the Web App URL is correctly pasted, (2) the deployment is set to "Anyone" access, (3) the Apps Script has been re-deployed after any code changes.
8
Re-deploy After Any Script Changes
Important

If you ever edit Code.gs, you must re-deploy — saving alone does not update the live Web App.

  1. In Apps Script, click Deploy → Manage deployments.
  2. Click the pencil ✏️ icon on your existing deployment.
  3. Change version to "New version".
  4. Click Deploy. The URL stays the same — no changes needed in the HTML.
